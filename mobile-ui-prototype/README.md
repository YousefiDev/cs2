# Mobile UI Prototype

این شاخه شامل یک نمونهٔ ساده و موبایل‌محور (HTML/CSS/JS) است که طراحی رابط کاربری موبایل را پیاده‌سازی می‌کند.

فایل‌ها:
- mobile-ui-prototype/index.html
- mobile-ui-prototype/styles.css
- mobile-ui-prototype/app.js

برای دیدن نمونه، شاخهٔ `feature/mobile-ui-prototype` را چک کن و `mobile-ui-prototype/index.html` را در مرورگر باز کن.
